# Small Business Accounting & Inventory Management System

A web-based system designed to help small businesses manage products, inventory, sales, purchases, and basic accounting records.

##  Project Status

In Development

##  Overview

The system aims to provide a centralized platform for managing day-to-day business operations such as inventory tracking, sales, purchases, and basic financial records.

##  Planned Features

- Product management
- Inventory/stock tracking
- Customer management
- Supplier management
- Sales management
- Purchase management
- Stock-in and stock-out records
- Low-stock alerts
- Revenue and expense tracking
- Basic accounting dashboard
- Database-backed records

##  Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
